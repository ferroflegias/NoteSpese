# 🧾 Gestione Note Spese 2026

Un'applicazione web sviluppata in **Python** e **Streamlit** per la gestione, reportistica ed esportazione automatizzata delle note spese aziendali.

Il sistema consente l'inserimento rapido delle spese da dispositivi desktop e mobile, l'archiviazione sicura su database PostgreSQL tramite **Supabase**, il ritaglio interattivo delle ricevute ed il caricamento di allegati (immagini e PDF). Permette inoltre di generare il report compilato direttamente su **modello Excel ufficiale** e un **documento PDF cumulativo in scala di grigi** per la stampa.

---

## 🚀 Caratteristiche Principali

* **➕ Inserimento Spese Intuitivo & Smart**:
  * Form dedicato con categorie predefinite (*Ristoranti, Parcheggi, Carburante, Telepass, Nolo, Altro*).
  * Gestione automatica della valuta estera con evidenziazione nel report Excel.
  * Trattamento nativo delle spese **Telepass** (senza obbligo di metodo di pagamento).

* **🖼️📄 Gestione Allegati (Foto & PDF)**:
  * Supporto a immagini (JPG, PNG) e documenti PDF con limite di 5MB per file.
  * **Crop Interattivo**: Strumento integrato per ritagliare e raddrizzare lo scontrino direttamente dallo smartphone o PC prima dell'upload.
  * Archiviazione permanente ed ordinata su **Supabase Storage** (`ID_UTENTE/ANNO-MESE/rec_...`).

* **📑 Registro Interattivo & Modifica**:
  * Tabella dinamica delle spese registrate.
  * Selezione rapida con un clic sulla riga della tabella per caricare il form di modifica o eliminazione (con rimozione contestuale dell'allegato dallo Storage).

* **📊 Reportistica & KPI in Tempo Reale**:
  * Calcolo istantaneo del totale mese, totale netto (esclusi Telepass e Carta Carburante) e totali isolati per categoria e metodo di pagamento.

* **📁 Esportazione Avanzata (Excel & PDF)**:
  * **Excel**: Compilazione automatica del modello ufficiale Excel (`Note spese 2026_NOMEDIPENDENTE.xlsx`) per mese singolo, intervallo di mesi o anno completo.
  * **PDF Cumulativo**: Generazione di un unico file PDF contenente tutti gli allegati (immagini impaginate a griglia + PDF uniti in coda) convertiti in **scala di grigi** per risparmiare toner in fase di stampa.

## 🛠️ Tech Stack

* **Frontend / UI**: [Streamlit](https://streamlit.io/)
* **Database & Cloud Storage**: [Supabase](https://supabase.com/) (PostgreSQL & Object Storage)
* **Image Processing & Crop**: [Pillow](https://python-pillow.org/), [streamlit-cropper](https://github.com/turner-robert/streamlit-cropper)
* **Generazione Excel**: [openpyxl](https://openpyxl.readthedocs.io/)
* **Generazione PDF & Merge**: [ReportLab](https://www.reportlab.com/), [pypdf](https://pypdf.readthedocs.io/)
* **Data Manipulation**: [pandas](https://pandas.pydata.org/)

---

## 📋 Prerequisiti

* Python 3.10+
* Account [Supabase](https://supabase.com) con:
  * Una tabella PostgreSQL chiamata `spese`.
  * Un bucket Storage denominato `allegati-spese`.
* File modello Excel nella radice del progetto: `Note spese 2026_NOMEDIPENDENTE.xlsx`.

## ⚙️ Configurazione ed Installazione

### 1. Clonare il repository
```
git clone [https://github.com/TUO_UTENTE/NOME_REPOSITORY.git](https://github.com/TUO_UTENTE/NOME_REPOSITORY.git)
cd NOME_REPOSITORY
```
### 2. Creare ed attivare un ambiente virtuale
```
python -m venv venv
source venv/bin/activate  # Su Linux/macOS
# venv\Scripts\activate   # Su Windows
```
### 3. Installare le dipendenze
```
pip install -r requirements.txt
```
### 4. Configurazione dei Secrets
```
Crea un file .streamlit/secrets.toml nella radice del progetto (o inseriscili nella sezione Secrets di Streamlit Cloud):
Ini, TOML

PASSWORD = "la_tua_password_di_accesso"
SUPABASE_URL = "[https://tuo-progetto.supabase.co](https://tuo-progetto.supabase.co)"
SUPABASE_KEY = "la_tua_anon_public_key"
```
### 5.🛢️ Struttura Database (SQL)
```
Per configurare la tabella su Supabase, esegui il seguente script SQL nel SQL Editor:
SQL

CREATE TABLE IF NOT EXISTS public.spese (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    data DATE NOT NULL,
    destinazione TEXT,
    scopo TEXT,
    categoria TEXT NOT NULL,
    metodo_pagamento TEXT,
    importo NUMERIC(10, 2) NOT NULL DEFAULT 0.00,
    km NUMERIC(10, 2) DEFAULT 0.00,
    note TEXT,
    allegato_path TEXT,
    valuta_straniera INT DEFAULT 0,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- Disabilita RLS per l'accesso semplice tramite API
ALTER TABLE public.spese DISABLE ROW LEVEL SECURITY;
```
### 6.🚀 Avvio dell'Applicazione
```
streamlit run app.py
L'applicazione sarà accessibile dal browser all'indirizzo http://localhost:8501.
```
